Student Marks Analysis System

## About the Project

This is a beginner-friendly Python project that analyzes student marks and displays the results using charts.

## Features

- Reads student marks from a CSV file.
- Displays student data using Pandas.
- Calculates average marks using NumPy and Pandas.
- Compares marks across subjects.
- Visualizes student marks using Matplotlib.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- CSV

## How to Run the Project

1. Install the required libraries

python -m pip install pandas numpy matplotlib

2. Run the program

python main.py
