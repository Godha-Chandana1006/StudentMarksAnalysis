Student Marks Analysis 

A Python-based data analysis project that analyzes student marks using Pandas, NumPy, and Matplotlib. It calculates student averages, subject averages, grades, pass/fail results, class pass percentage, and identifies the top-performing student. It also generates a visualization and records application events in a log file.

## Features
- Read student marks from a CSV file using Pandas.
- Validate required CSV columns.
- Calculate each student's average marks.
- Calculate average marks for each subject.
- Assign grades based on student averages.
- Determine whether each student passes or fails.
- Calculate class pass and fail percentages.
- Identify the top-performing student.
- Visualize student averages using Matplotlib.
- Record application events and errors using Python logging.
- Handle missing files and data-processing errors.

## Sample Dataset

The "student_data.csv" file contains student names and marks in three subjects.

Student,Python,Maths,English
Anu,85,90,80
Ravi,70,75,80
Priya,95,92,90
Kiran,60,65,70

To test the fail condition, change Kiran's marks to "35,65,70". Since the Python mark is below 40, the student should receive a Fail result.

## Grade Criteria

Average Marks| Grade
90 and above| A
80–89.99| B
70–79.99| C
60–69.99| D
Below 60| F

Pass criteria: A student must score at least 40 marks in every subject to pass.

## Installation and Setup

1. Clone the repository

git clone https://github.com/Godha-Chandana1006/StudentMarksAnalysis.git

2. Open the project folder

cd StudentMarksAnalysis

3. Install dependencies

pip install -r requirements.txt

The "requirements.txt" file should contain:

pandas
numpy
matplotlib

4. Run the project

python main.py

Make sure "student_data.csv" is present in the project folder before running the program.
